# BUSINESS ENERGY FORUM 2026 — сайт-визитка

Одностраничный сайт мероприятия **BUSINESS ENERGY FORUM 2026** — закрытой B2B-площадки
нефтегазовой отрасли (12 сентября 2026, Renaissance Aktau Hotel).

Сделан на **React + Vite**. Весь контент сайта взят из предоставленных материалов
и ничего не выдумано: нет вымышленных спикеров, компаний, цен, ссылок или контактов.

## 3. Подробная инструкция: установка и запуск локально

### Шаг 1. Установите Node.js

Vite требует Node.js версии 18 или новее.

1. Откройте сайт [nodejs.org](https://nodejs.org).
2. Скачайте версию **LTS** (рекомендуемая) для Windows.
3. Запустите установщик и нажмите **Next** на всех шагах, оставляя настройки по умолчанию.
4. После установки откройте **PowerShell** или **Terminal** и проверьте версию:

```bash
node -v
npm -v
```

Если команды показали номера версий — всё готово.

### Шаг 2. Распакуйте архив проекта

1. Найдите файл `business-energy-forum-2026.zip`, который вы скачали.
2. Нажмите на него правой кнопкой мыши → **Извлечь всё...** (Extract All...).
3. Выберите папку, например `C:\Projects\`, и нажмите **Извлечь**.
4. В результате у вас появится папка `C:\Projects\business-energy-forum-2026`.

### Шаг 3. Откройте проект в VS Code

1. Откройте **VS Code**.
2. В верхнем меню выберите **File → Open Folder...**.
3. Выберите папку `business-energy-forum-2026`, которую вы распаковали.
4. Нажмите **Select Folder**.

### Шаг 4. Откройте терминал в VS Code

1. В верхнем меню VS Code выберите **Terminal → New Terminal**.
2. Внизу экрана появится панель терминала — вводить команды нужно туда.

### Шаг 5. Установите зависимости проекта

В терминале введите:

```bash
npm install
```

и нажмите **Enter**. Дождитесь, пока команда закончит работу (появится новая строка
для ввода). Эта команда скачивает React, Vite и другие библиотеки, необходимые
для работы сайта — они не входят в архив, чтобы он был компактным.

### Шаг 6. Запустите сайт локально

```bash
npm run dev
```

В терминале появится сообщение примерно такого вида:

```
  VITE ready

  ➜  Local:   http://localhost:5173/
```

### Шаг 7. Откройте сайт в браузере

1. Зажмите **Ctrl** и кликните по ссылке `http://localhost:5173/` в терминале —
   либо просто скопируйте её и вставьте в адресную строку браузера.
2. Сайт откроется. Любые изменения кода будут обновляться в браузере автоматически.

### Шаг 8. Остановите локальный сервер

Когда закончите просмотр — вернитесь в терминал VS Code и нажмите **Ctrl + C**.
Если появится вопрос `Terminate batch job (Y/N)?`, введите `Y` и нажмите **Enter**.

## 4. Production-сборка

Когда сайт готов к публикации, соберите оптимизированную версию:

```bash
npm run build
```

Vite создаст папку `dist/` с готовыми файлами сайта (HTML, CSS, JS), оптимизированными
для продакшена.

Проверить, как сайт будет выглядеть в production-режиме, можно локально:

```bash
npm run preview
```

Эта команда запустит локальный сервер, показывающий именно то, что попадёт в `dist/`.
Ссылка на предпросмотр тоже появится в терминале (обычно `http://localhost:4173/`).

## 5. Как загрузить проект на GitHub

### Шаг 9. Создайте аккаунт на GitHub (если его ещё нет)

1. Откройте [github.com](https://github.com).
2. Нажмите **Sign up** в правом верхнем углу.
3. Введите email, пароль, имя пользователя и следуйте подсказкам на экране.
4. Подтвердите почту по ссылке, которая придёт на ваш email.

### Шаг 10. Установите Git на Windows (если ещё не установлен)

1. Проверьте, установлен ли Git — в терминале VS Code введите:

   ```bash
   git --version
   ```

2. Если появилась ошибка "не является внутренней или внешней командой" —
   скачайте Git с [git-scm.com](https://git-scm.com/download/win) и установите,
   оставляя настройки по умолчанию (**Next** на всех шагах).
3. Перезапустите VS Code и снова проверьте `git --version`.

### Шаг 11. Создайте новый репозиторий на GitHub

1. На сайте GitHub нажмите значок **+** в правом верхнем углу → **New repository**.
2. В поле **Repository name** введите, например: `business-energy-forum-2026`.
3. Оставьте репозиторий **Public** (или выберите **Private**, если хотите скрыть код).
4. **Не** ставьте галочку "Add a README file" — README уже есть в проекте.
5. Нажмите зелёную кнопку **Create repository**.
6. GitHub покажет страницу с командами — скопируйте оттуда ссылку вида
   `https://github.com/ваш-логин/business-energy-forum-2026.git`. Она понадобится
   на следующем шаге.

### Шаг 12. Загрузите проект в репозиторий через Git

В терминале VS Code (в папке проекта) выполните команды по очереди, нажимая
**Enter** после каждой:

```bash
git init
```
Создаёт локальный Git-репозиторий в папке проекта.

```bash
git add .
```
Добавляет все файлы проекта в список для сохранения (кроме указанных в `.gitignore`,
например `node_modules`).

```bash
git commit -m "Initial commit"
```
Сохраняет текущее состояние проекта как первую версию с комментарием.

```bash
git branch -M main
```
Называет основную ветку `main` (стандарт GitHub).

```bash
git remote add origin ВСТАВЬТЕ_СЮДА_ВАШУ_ССЫЛКУ_С_GITHUB
```
Подключает ваш локальный проект к репозиторию на GitHub. Вместо
`ВСТАВЬТЕ_СЮДА_ВАШУ_ССЫЛКУ_С_GITHUB` вставьте ссылку, которую вы скопировали
на Шаге 11 (например `https://github.com/ваш-логин/business-energy-forum-2026.git`).

```bash
git push -u origin main
```
Загружает проект на GitHub. При первой загрузке может появиться окно входа —
войдите в свой аккаунт GitHub.

7. Обновите страницу репозитория на GitHub в браузере — вы увидите загруженные файлы.

## 6. Как опубликовать сайт через Vercel

### Шаг 13. Создайте аккаунт на Vercel

1. Откройте [vercel.com](https://vercel.com).
2. Нажмите **Sign Up**.
3. Выберите **Continue with GitHub** и разрешите Vercel доступ к вашему аккаунту GitHub —
   это самый простой способ, дальше не нужно ничего вводить вручную.

### Шаг 14. Импортируйте проект

1. В панели Vercel нажмите кнопку **Add New...** → **Project**.
2. В списке репозиториев найдите `business-energy-forum-2026` и нажмите
   **Import** рядом с ним.
   Если репозиторий не отображается — нажмите **Adjust GitHub App Permissions**
   и разрешите Vercel доступ к этому репозиторию.

### Шаг 15. Настройки проекта

Vercel автоматически распознаёт, что это проект на **Vite**, и сам подставляет
правильные настройки:

- **Framework Preset:** Vite
- **Build Command:** `vite build` (уже подставлено автоматически)
- **Output Directory:** `dist` (уже подставлено автоматически)
- **Install Command:** `npm install` (уже подставлено автоматически)

Для этого проекта дополнительно ничего менять не нужно — все поля можно оставить
как есть.

### Шаг 16. Запустите публикацию

1. Нажмите синюю кнопку **Deploy**.
2. Подождите 1–2 минуты, пока Vercel установит зависимости и соберёт сайт —
   на экране будет идти лог сборки.
3. Когда сборка завершится, появится надпись **Congratulations!** и превью сайта.

### Шаг 17. Получите ссылку на сайт

1. На странице проекта в Vercel нажмите на превью-картинку сайта или на ссылку
   вида `business-energy-forum-2026.vercel.app` — это и есть готовый адрес сайта.
2. Эту ссылку можно копировать и отправлять кому угодно — сайт уже доступен всем
   в интернете.

## 7. Как обновить сайт после изменений

1. Внесите изменения в файлы проекта в VS Code (например, поменяйте текст в
   `src/sections/Contacts.jsx`).
2. Сохраните файл (**Ctrl + S**).
3. Проверьте изменения локально командой `npm run dev`, если хотите убедиться,
   что всё выглядит правильно.
4. В терминале VS Code выполните:

   ```bash
   git add .
   git commit -m "Описание изменений"
   git push
   ```

5. Vercel автоматически обнаружит новый пуш в репозиторий на GitHub и запустит
   новую сборку — никаких дополнительных действий в Vercel делать не нужно.
6. Через 1–2 минуты обновлённая версия появится по той же ссылке.

## 8. Про домен

- Сразу после первого деплоя сайт уже доступен по бесплатному адресу вида
  `business-energy-forum-2026.vercel.app`. Найти его можно на странице проекта
  в Vercel, в разделе **Domains**.
- Если позже вы захотите использовать собственный домен (например
  `businessenergyforum.kz`):
  1. Купите домен у любого регистратора доменов (например, Namecheap, GoDaddy
     или местного регистратора для домена `.kz`). Anthropic и Vercel домены не продают.
  2. В проекте на Vercel откройте вкладку **Settings → Domains** и введите
     купленный домен.
  3. Vercel покажет, какие DNS-записи нужно добавить у вашего регистратора —
     обычно это запись **A** (указывает на IP-адрес Vercel) или **CNAME**
     (указывает на `cname.vercel-dns.com`). Точные значения Vercel покажет
     на экране после ввода домена — они могут отличаться, поэтому используйте
     именно то, что покажет сам Vercel, а не сторонние инструкции.
  4. После добавления записей у регистратора подождите от нескольких минут до
     24–48 часов, пока изменения DNS распространятся, — Vercel сам подтвердит,
     когда домен заработает.
